## Límite deliberado de esta fase

- Se configura npm, TypeScript estricto, Vite, ESLint y Prettier.
- `src/tooling/smoke.ts` e `index.html` son un **diagnóstico temporal**, no una interfaz de bóveda.
- `public/manifest.json` NO se modifica. Vite configura `publicDir: false` para no distribuir un manifiesto incompleto.
- El bundle de esta fase **no es una extensión instalable**. Eso se prepara en AV-008–AV-010.
- No instalar plugins de Vite que inyecten scripts remotos; no agregar telemetría.

## Dependencias

Se fijan versiones directas exactas en `package.json`. Se selecciona TypeScript 5.9.3 porque `typescript-eslint` 8.72.1 declara compatibilidad con TypeScript menor que 6.1, no con TypeScript 7. Vite 8.3.5 es una herramienta **solo de desarrollo**.

El archivo `package-lock.json` NO puede rellenarse manualmente: incluye el árbol transitivo, URL e integridad de paquetes obtenidos del registro npm. Genéralo en el equipo conectado:

```bash
cd ~/proyectos/AegisVault
node --version
npm --version
npm install --package-lock-only
npm ci
npm run check
```

`npm install --package-lock-only` resuelve el árbol de dependencias y genera `package-lock.json`; `npm ci` usa exclusivamente ese archivo y falla si `package.json` deja de concordar. **Sube ambos** (`package.json` + `package-lock.json`) en el mismo commit tras verificar.

### Diagnóstico del servidor Vite (WSL)

## Comprobaciones exigidas antes de marcar terminado

1. `npm ci` ejecutado exitosamente desde una copia limpia (WSL).
2. `npm run check` sin errores en WSL.
3. `npm run dev` muestra la página de diagnóstico local en WSL.
4. `npm ci` y `npm run check` superados en Windows PowerShell.
5. `dist/av007-smoke.js` existe y `dist/manifest.json` no existe.
6. `package-lock.json` versionado y Git limpio tras commit.
7. No se añaden secretos, credenciales, telemetría ni datos reales.

## Errores habituales

- `EBADENGINE`: actualizar Node a 22.12+ o 24+ (ver las restricciones en `package.json`).
- `npm ci` dice que no existe lock: ejecutar `npm install --package-lock-only` **una sola vez**, revisar y versionar el resultado.
- `EAI_AGAIN`/`ENOTFOUND`: problema de DNS/conectividad al registro; no crear un lock ficticio.
- `ENOENT` de `src/tooling/smoke.ts`: revisar la extracción del ZIP.
- Falla `format:check`: ejecutar `npm run format`, revisar los cambios y repetir `npm run check`.
- Error por dependencias nativas de otra plataforma: eliminar `node_modules` **en ese sistema** y ejecutar `npm ci`.
